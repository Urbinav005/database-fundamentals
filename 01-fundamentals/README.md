# 🧠 Database Fundamentals

This section covers the fundamental concepts required to understand how databases work.

---

## 📌 What is a Database?

A database is an organized collection of data that can be stored, accessed, managed, and updated efficiently.

Databases are used in applications, websites, businesses, banking systems, universities, social networks, and many other systems.

---

## 🗄️ What is a DBMS?

A **Database Management System (DBMS)** is software used to create, manage, access, and manipulate databases.

### Examples

- PostgreSQL
- Oracle Database
- MySQL
- Microsoft SQL Server
- MongoDB

---

## 🧩 Main Database Concepts

### Data

Individual pieces of information stored in a database.

### Table

A structure used in relational databases to organize data into rows and columns.

### Record

A single row containing information about an entity.

### Field

A column that represents a specific attribute.

### Schema

The logical structure that defines how data is organized inside a database.

---

## 🏛️ Database Models

There are different ways to organize and represent data.

### Relational

Data is organized into tables with predefined relationships.

Examples:

- PostgreSQL
- Oracle
- MySQL

### Non-Relational

Data is stored using models such as documents, key-value pairs, graphs, or wide-column structures.

Examples:

- MongoDB
- Redis
- Neo4j

---

## 🔑 Important Concepts

Some of the most important concepts studied in databases are:

- Primary Keys
- Foreign Keys
- Relationships
- Constraints
- Normalization
- SQL
- Transactions
- Data Integrity
- Database Design
